## Форматирование текста

- **Жирный текст** выделяется двумя звёздочками.
- *Курсив* выделяется одной звёздочкой.
- ~~Зачёркнутый текст~~ выделяется двумя тильдами.
- `Моноширный текст` выделяется обратными кавычками.

## Списки

### Маркированный список
- Первый пункт
- Второй пункт
- Третий пункт

### Нумерованный список
1. Первый шаг
2. Второй шаг
3. Третий шаг

### Вложенный список
- Основной пункт
  - Вложенный пункт 1
  - Вложенный пункт 2
    - Подвложенный пункт 2.1
    - Подвложенный пункт 2.2
- Ещё один основной пункт
